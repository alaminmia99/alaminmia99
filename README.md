## 🔬 Current Research

### Machine Learning-Assisted QSAR Modelling of Human Topoisomerase I Inhibitors

My MSc research focuses on developing and evaluating computational approaches
for **Human Topoisomerase I (TOP1) inhibitors**, integrating experimental
bioactivity data with cheminformatics and machine learning.

The workflow includes:

- 🧹 Bioactivity data collection and curation
- ⚗️ IC₅₀ / pIC₅₀ activity processing
- 🧬 Molecular structure standardisation
- 📊 Molecular descriptor calculation
- 🧩 Molecular fingerprints
- 🤖 Machine learning-based QSAR modelling
- 🎯 Molecular docking
- 🔗 Docking + molecular descriptor hybrid modelling
- 📈 Model validation and performance evaluation
- 🔍 Applicability domain analysis
